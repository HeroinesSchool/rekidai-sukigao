HEROINES SCHOOL歴代好き顔9選

GitHub Pages用の一式です。
- index.html
- images/01.jpg ～ images/48.jpg

公開方法:
1. 新しいGitHubリポジトリを作成
2. index.html と images フォルダをそのままアップロード
3. Settings > Pages > Deploy from a branch > main / root を選択

選考ロジック:
第1段階: 48人を 10/10/10/9/9 の5グループにランダム分割。各グループから何人でも選択可（合計12人以上）。
第2段階: 4人から1位・2位を選択。落選者だけを敗者プールに集めて再抽選し、4人以上いる限り同じ処理を繰り返す。最後に4人未満になったメンバーのみここで脱落。
第3段階: 2択比較を使った挿入順位決定で全通過者を順位付け。
結果: TOP9を 4・5・6 / 2・1・3 / 7・8・9 の3×3で表示。結果画像保存と全順位表示に対応。

途中経過はlocalStorageに自動保存されます。
